Kaitao Liao · Advisor: Enlu Zhou · Georgia Tech ISyE MAIN IDEA Low-cost pseudo-labels guide the diffusion model toward the global optimum with only a few real function evaluations. 01 Why compare with CE and PSA? They represent two established ways to search without gradients. CE Cross-Entropy Method CE repeatedly fits a sampling distribution to the best candidates found so far. Why it matters: It provides a distribution-learning baseline without a diffusion model. PSA Population-Based Simulated Annealing PSA uses a population and a cooling temperature to gradually shift from exploration to exploitation. Why it matters: It provides a classical temperature-driven search baseline. Together, CE and PSA test whether conditional diffusion adds value beyond distribution fitting and classical annealing. 02 What do the four objective functions test? Each function makes optimization difficult in a different way. Ackley function Many local traps A nearly flat outer region and many local maxima make premature convergence easy. Search domain: Global maximum: At: Pintér function Neighboring variables interact Each coordinate depends on its neighbors, so the dimensions cannot be optimized independently.
